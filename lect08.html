Intent Diagram

Complete Code Answer
// Component Interface public interface Item {{ double getprice(); void showInfo(); }} // Leaf public class Product implements Item {{ private double price; private String name; @Override public double getprice() {{ return price; }} }} // Composite public class Box implements Item {{ private List<Item> list = new ArrayList<>(); public void addproduct(Item p) {{ list.add(p); }} @Override public double getprice() {{ double sum = 0; for (Item item : list) {{ sum += item.getprice(); }} return sum; }} }}
الشرح:

Question 4DIAGRAM

Structure Diagram

💡 Hint: Slide 9

Task: Write code based on this diagram.

Complete Code Answer
// Complete Structure public interface Component {{ void execute(); }} public class Leaf implements Component {{ @Override public void execute() {{ /* work */ }} }} public class Composite implements Component {{ private List<Component> children = new ArrayList<>(); public void add(Component c) {{ children.add(c); }} @Override public void execute() {{ for (Component child : children) {{ child.execute(); }} }} }}
الشرح:
البنية الكاملة للـ Composite Pattern.
