Q2: [CLO2] Code Completion - Adapter Pattern Marks: 6

Complete the following Adapter pattern implementation. We have a legacy system with a LegacyPrinter class that uses printDocument() method. We need to adapt it to work with a new Printer interface that expects a print() method.

// Target Interface interface Printer { void ________(); // Blank 1 } // Adaptee (Legacy class) class LegacyPrinter { public void ________() { // Blank 2 System.out.println("Legacy Printer is printing a document."); } } // Adapter class PrinterAdapter implements ________ { // Blank 3 private LegacyPrinter ________; // Blank 4 public PrinterAdapter(LegacyPrinter legacyPrinter) { this.legacyPrinter = legacyPrinter; } @Override public void print() { legacyPrinter.________(); // Blank 5 } } // Client code public class Main { public static void main(String[] args) { LegacyPrinter legacy = new LegacyPrinter(); Printer adapter = new ________(legacy); // Blank 6 adapter.print(); } }
Complete Code Answer
interface Printer { void print(); } class LegacyPrinter { public void printDocument() { System.out.println("Legacy Printer is printing a document."); } } class PrinterAdapter implements Printer { private LegacyPrinter legacyPrinter; public PrinterAdapter(LegacyPrinter legacyPrinter) { this.legacyPrinter = legacyPrinter; } @Override public void print() { legacyPrinter.printDocument(); } } public class Main { public static void main(String[] args) { LegacyPrinter legacy = new LegacyPrinter(); Printer adapter = new PrinterAdapter(legacy); adapter.print(); } }

Blank Answers:

Blank 1: print | Blank 2: printDocument | Blank 3: Printer | Blank 4: legacyPrinter | Blank 5: printDocument | Blank 6: PrinterAdapter

الشرح:

ده Adapter Pattern الكامل من Lec 6 (Slides 14-17). أول حاجة عندنا الـ Target Interface اللي هو Printer بيحتوي على method اسمها print(). بعدين عندنا الـ Adaptee اللي هو LegacyPrinter class وده الكود القديم اللي عنده method اسمها printDocument(). الـ PrinterAdapter بيعمل implements للـ Printer interface وجواه بيمسك مرجع للـ LegacyPrinter. لما الـ Client يستدعي print() method على الـ Adapter، الـ Adapter بيحولها لاستدعاء printDocument() على الـ LegacyPrinter. كده الـ Adapter بيخلي الكود القديم يشتغل مع الـ Interface الجديد من غير ما نغير في الكود الأصلي.

Q3: [CLO2] Code Completion - Bridge Pattern Marks: 10

Complete the following Bridge pattern implementation for shapes with different colors. The pattern separates shape abstraction from color implementation.

// Implementer interface public interface Color { public void ________(); // Blank 1 } // Concrete Implementer 1 public class RedColor implements ________ { // Blank 2 @Override public void applyColor() { System.out.println("Red -->"); } } // Concrete Implementer 2 public class BlueColor implements Color { @Override public void ________() { // Blank 3 System.out.println("Blue -->"); } } // Abstraction public abstract class Shape { protected ________ color; // Blank 4 public Shape(Color color) { this.________ = color; // Blank 5 } abstract public void ________(); // Blank 6 } // Refined Abstraction public class Triangle extends ________ { // Blank 7 public Triangle(Color color) { super(________); // Blank 8 } @Override public void applyColor() { System.out.println("Triangle is colored with "); color.________(); // Blank 9 } } // Client code public class Main { public static void main(String[] args) { Shape redTriangle = new Triangle(new RedColor()); redTriangle.________(); // Blank 10 Shape blueTriangle = new Triangle(new BlueColor()); blueTriangle.applyColor(); } }
Complete Code Answer
public interface Color { public void applyColor(); } public class RedColor implements Color { @Override public void applyColor() { System.out.println("Red -->"); } } public class BlueColor implements Color { @Override public void applyColor() { System.out.println("Blue -->"); } } public abstract class Shape { protected Color color; public Shape(Color color) { this.color = color; } abstract public void applyColor(); } public class Triangle extends Shape { public Triangle(Color color) { super(color); } @Override public void applyColor() { System.out.println("Triangle is colored with "); color.applyColor(); } } public class Main { public static void main(String[] args) { Shape redTriangle = new Triangle(new RedColor()); redTriangle.applyColor(); Shape blueTriangle = new Triangle(new BlueColor()); blueTriangle.applyColor(); } }

Blank Answers:

Blank 1: applyColor | Blank 2: Color | Blank 3: applyColor | Blank 4: Color | Blank 5: color | Blank 6: applyColor | Blank 7: Shape | Blank 8: color | Blank 9: applyColor | Blank 10: applyColor

الشرح:

ده Bridge Pattern الكامل من Lec 7 (Slides 15-22). الـ Pattern ده بيفصل الـ Abstraction (الأشكال) عن الـ Implementation (الألوان) عشان يتطوروا بشكل مستقل. أول حاجة عندنا الـ Implementer interface اللي هو Color وفيه method واحدة applyColor(). بعدين عملنا Concrete Implementers (RedColor, BlueColor) كل واحد بيعمل implements للـ Color interface. الـ Shape abstract class (الـ Abstraction) بيحتوي على reference للـ Color interface. لما نعمل Refined Abstraction زي Triangle بيستقبل Color في الـ Constructor وبيمررها للـ parent class. لما نستدعي applyColor() على الـ Triangle، هو بيستخدم الـ color reference عشان يطبق اللون. كده نقدر نضيف أشكال وألوان جديدة من غير ما نعمل explosion في عدد الكلاسات.
