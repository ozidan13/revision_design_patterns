Question 3DIAGRAM

Separation of Concerns

💡 Hint: Slide 14

Task: Write code based on this diagram.

Complete Code Answer
// Solution: Separate GUI from Business Logic // GUI Layer (only displays and captures input) class Button {{ private Command command; public void setCommand(Command cmd) {{ this.command = cmd; }} public void onClick() {{ command.execute(); // Delegate to command }} }} // Business Logic Layer (wrapped in commands) interface Command {{ void execute(); }} class CopyCommand implements Command {{ private Editor editor; @Override public void execute() {{ editor.copyText(); }} }} // Benefits: // - GUI doesn't know about business logic // - Easy to reuse commands (toolbar, menu, shortcuts) // - Easy to extend (add new commands)
الشرح:
الحل: فصل GUI عن Business Logic. Button بيمسك Command object وبينفذها.
Question 4DIAGRAM

Structure Diagram

💡 Hint: Slide 19

Task: Write code based on this diagram.

Complete Code Answer
// Complete Command Pattern Structure // 1. Command Interface interface Command {{ void execute(); }} // 2. Receiver (knows how to perform operations) class Receiver {{ public void action() {{ // Actual work }} }} // 3. Concrete Command (connects invoker to receiver) class ConcreteCommand implements Command {{ private Receiver receiver; public ConcreteCommand(Receiver receiver) {{ this.receiver = receiver; }} @Override public void execute() {{ receiver.action(); }} }} // 4. Invoker (asks command to execute) class Invoker {{ private Command command; public void setCommand(Command cmd) {{ this.command = cmd; }} public void executeCommand() {{ command.execute(); }} }} // Client Receiver receiver = new Receiver(); Command cmd = new ConcreteCommand(receiver); Invoker invoker = new Invoker(); invoker.setCommand(cmd); invoker.executeCommand();
الشرح:
البنية الكاملة: Command، Receiver، Concrete Command، Invoker، والـ Client.
